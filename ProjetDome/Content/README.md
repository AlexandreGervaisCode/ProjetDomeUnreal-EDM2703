# Folder Organisation
### Audio
All the static audio files (.mp3, .wav, etc).

### Blueprints
All of the Blueprints files.

### Fonts
Contains the project's fonts (if we have any).

### Images
All of the images (.png, .jpg, .webp, etc) that AREN'T textures.

### Maps
All of the maps/scenes of the project.

### Materials
All of the materials used.

### MetaSounds
All of the MetaSound files (dynamic audio) for the project.

### Models
All of the 3D models used.

### Scripts
All of the code scripts (.cpp, .cs, .py, etc).

### Shaders
All of the shaders made.

###  Textures
All of the texture files (.jpg, .png).
